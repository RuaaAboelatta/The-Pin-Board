# The Pin Board

A beautiful, interactive task management board with a sticky note / pin board theme. 
Create, organize, and track your tasks with an intuitive interface.

## Features
- Create Tasks -> Add tasks with title, description, and priority
- Task Filtering -> View All, Active, or Completed tasks
- Local Storage -> Tasks persist after page refresh
- Responsive Design -> Works on desktop, tablet, and mobile
- Smooth Animations -> Beautiful transitions and interactions

## Technologies
- HTML5 
- CSS3 
- Vanilla JavaScript
- Font Awesome
- Google Fonts
- Local Storage
